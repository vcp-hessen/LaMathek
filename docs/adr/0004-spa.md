# Single-page application for the UI

The LaMathek UI is a single-page application. It talks to the Python server over HTTP. The server does not render pages as templates; it only renders documents that leave the app: mails and PDF lists ([0015](./0015-pdf-weasyprint.md)).

The UI framework is Vue ([0007](./0007-vue-client.md)) with DaisyUI ([0008](./0008-daisyui.md)).
