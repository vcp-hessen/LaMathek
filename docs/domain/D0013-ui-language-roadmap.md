# D0013 — Oberfläche und Roadmap

## Entscheidung

- Die **Benutzeroberfläche** ist **Deutsch** (siehe auch ADR German i18n).
- Ein **öffentlicher Katalog** ist eine spätere Idee, kein Bestandteil der aktuellen Entscheidungen.

## Konsequenzen

- `web/src/locales/de.json` als Haupt-UI-Locale; Domain-Dokumente Deutsch; CODE/ADR Englisch wo üblich.

## Nicht-Ziele

- Mehrsprachige UI in der ersten Ausbaustufe.
