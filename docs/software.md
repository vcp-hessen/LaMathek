# Produkt- und Software-Übersicht

LaMathek dokumentiert Material von VCP Hessen. Verbindliche **Produktregeln** stehen in **[docs/domain/](domain/README.md)** (Deutsch). **Begriffe** in [CONTEXT.md](../CONTEXT.md). **Technik** in [docs/adr/](adr/) (Englisch).

**Produktregeln nur in `docs/domain/` pflegen** — diese Datei ist der Index, kein zweiter Regeltext.

## Auf einen Blick

LaMathek erfasst nur Material von VCP Hessen (nicht Stamm/Bezirk/Bund). Verleihe laufen über Entwurf, Prüfung, Packen, Abholung, Rückgabe und Übernahme; Positionen haben eigene Status; Mail-Receipts schließen Phasen ab. Details in den Domain-Records unten.
